# AI 辅助文献检索与论文阅读

AI 可以帮助你扩大候选论文、统一阅读字段和发现遗漏，但不能证明检索已经完整，也不能替代对原文方法、实验和限制的阅读。

## 适用任务

- 将一个模糊方向拆成检索关键词。
- 从标题和摘要中初筛候选论文。
- 把论文整理成统一文献矩阵。
- 对比多篇论文的问题、假设、数据和实验。
- 根据已读论文生成待核验的问题清单。

## 不适用任务

- 直接判断“没有人做过”。
- 只凭模型记忆生成相关工作。
- 只读 AI 摘要就引用论文。
- 在未查看原文时评价实验公平性。
- 把模型生成的作者、标题、年份或 DOI 直接写入论文。

## 第一步：先建立检索问题

不要直接输入“帮我找 RAG 论文”。先写清楚：

```text
研究对象：研究什么系统或现象？
目标问题：希望解释、预测或改进什么？
关键条件：在哪些数据、任务或约束下？
排除项：哪些方向暂时不考虑？
时间边界：是否关注近期工作？
```

让 AI 生成的是关键词候选，不是最终检索结论。

建议输出四组词：

| 类型 | 示例 |
| --- | --- |
| 任务词 | retrieval-augmented generation, question answering |
| 现象词 | conflicting evidence, attribution error |
| 方法词 | reranking, evidence aggregation |
| 评估词 | faithfulness, robustness, calibration |

随后在学术检索平台中实际搜索，并记录使用过的查询式。

## 第二步：种子论文优先于大规模收集

先确认：

- 1 至 3 篇综述或领域地图；
- 3 至 5 篇奠基工作；
- 5 至 10 篇近年代表工作；
- 3 至 5 篇与你问题最相似的工作；
- 若干负结果、复现报告或失败线索。

AI 可以根据你提供的真实论文元数据做分类，但不能替你确认论文是否真实、是否相关。

## 第三步：三层阅读

### 快筛

输入标题、摘要、引言贡献段和实验概览，让 AI 按以下字段整理：

```text
问题
核心方法
主要数据集
评价指标
作者声称的贡献
是否与你的课题直接相关
仍需人工查看的位置
```

快筛结果只能决定是否继续读，不能直接进入 related work。

### 结构化阅读

至少提供方法、实验、限制和附录中的关键部分，要求：

- 每个判断给出原文位置；
- 区分作者主张与模型推断；
- 标出缺少证据的字段；
- 不允许根据常识补全实验设置。

### 深读与复现

AI 可以解释公式、代码和配置，但应同步检查：

- 变量定义是否与论文一致；
- 伪代码是否省略关键步骤；
- 开源实现是否对应论文版本；
- 默认参数是否与报告实验一致；
- 模型解释是否能通过小例子或运行验证。

## 第四步：建立可追溯文献矩阵

推荐字段：

| 字段 | 核验要求 |
| --- | --- |
| 研究问题 | 定位到摘要或引言 |
| 核心假设 | 区分作者明确表述和你的归纳 |
| 方法 | 定位到方法节和总图 |
| 数据集 | 定位到实验设置 |
| baseline | 检查是否为强 baseline、是否公平 |
| 指标 | 检查定义和方向 |
| 主要结果 | 保存表格编号和具体数值 |
| 局限 | 同时记录作者限制和你发现的限制 |
| closest-work 关系 | 写清相同点和机制差异 |
| 与课题关系 | 记录支持、冲突或待验证之处 |

不要让 AI 输出无法回到原文的“综合结论”。

## 第五步：用 AI 做交叉论文批判

在你已经读过论文后，可以要求 AI 比较：

- 各论文是否解决同一个问题；
- 方法差异是否只是实现差异；
- 训练数据、模型规模和预算是否可比；
- 使用的指标是否真正对应论文主张；
- 哪些结论依赖共同但未验证的假设；
- 哪些失败条件在多篇论文中重复出现。

这一步用于生成待验证问题，不用于直接宣布研究 gap。

## 文献检索停止条件

不要因为已经收集很多论文而停止。至少满足：

- 能画出主要方法路线；
- 能说清代表论文之间的关系；
- 能指出最接近你的 3 至 5 篇工作；
- 新增论文大多不再改变分类结构；
- 关键主张都能定位到原文；
- 已记录可能反对自己想法的工作。

## 常见失败

- 只用一个关键词检索。
- 把 AI 推荐列表当成完整文献集合。
- 只读摘要，不看实验和限制。
- 只保存支持自己 idea 的论文。
- 把作者贡献段直接复制为真实贡献。
- 文献矩阵没有来源位置，几周后无法复查。
- 使用模型记忆中的论文信息，但没有验证版本和年份。

## 最小提示词

```text
请只基于我提供的论文内容做结构化整理。
每个事实标注章节、表格或原文位置。
区分：作者明确主张、可以从材料推导、材料不足。
不要补充未提供的论文、实验数字、引用或结论。
最后列出我仍需要人工阅读和核验的位置。
```
