# Prism 与 Overleaf：AI LaTeX 写作工作流

本文讨论的是 **OpenAI Prism AI LaTeX 编辑器**，不是 GraphPad Prism。

目标不是判断哪个编辑器“更先进”，而是根据协作、AI 辅助、版本控制、隐私和投稿要求选择合适流程。

## 先做选择

| 需求 | 优先考虑 |
| --- | --- |
| 稳定的传统 LaTeX 协作、模板生态、导师已经在使用 | Overleaf |
| 希望 AI 直接理解完整项目并辅助排版、校对和编译诊断 | Prism |
| 强版本控制、本地工具链、自定义脚本 | 本地 LaTeX + Git |
| 团队成员不熟悉 LaTeX | Overleaf 或 Prism，但必须提供模板和目录规范 |
| 稿件、数据或代码有严格保密要求 | 先核对单位政策；必要时使用本地环境 |

工具选择不能替代课题组协作习惯。导师和合作者已经稳定使用某个平台时，迁移成本可能高于 AI 带来的收益。

## Prism 适合做什么

Prism 是原生支持 LaTeX 的 AI 工作区。它可以在项目上下文中辅助：

- 生成表格、公式、图片环境等 LaTeX 片段；
- 解释和修复编译错误；
- 校对语言、结构和逻辑跳跃；
- 管理引用和检索候选文献；
- 在同一项目中协作、编译和预览；
- 从 Overleaf 下载 ZIP 后导入项目。

但 AI 能修改 LaTeX，不意味着它能判断研究结论。以下内容必须人工核验：

- 引用是否真实存在；
- 引用是否真的支持相应陈述；
- 公式是否与方法定义一致；
- 表格数字是否来自实验结果；
- AI 改写是否扩大了结论范围；
- 自动修复是否改变了文档语义。

## Overleaf 适合做什么

Overleaf 的主要优势是成熟的在线 LaTeX 协作：

- 期刊和会议模板多；
- 合作者使用习惯成熟；
- 评论、修订和实时协作稳定；
- 无需安装本地 LaTeX；
- 适合导师直接批注和多人修改。

它不自动解决科研写作问题。多人协作仍需要明确文件所有权、版本节点和修改规则。

## 推荐项目结构

```text
paper/
├── main.tex
├── sections/
│   ├── introduction.tex
│   ├── related_work.tex
│   ├── method.tex
│   ├── experiments.tex
│   └── conclusion.tex
├── figures/
├── tables/
├── references.bib
├── appendix.tex
└── response/
    └── rebuttal.tex
```

规则：

- 每个 section 单独文件；
- 图片文件名描述内容，不使用 `image1.png`；
- 表格数据尽量由脚本生成；
- 自定义命令集中定义；
- 不在正文中手工复制同一组实验数字；
- 投稿前保存可独立编译的快照。

## Prism 最小使用流程

1. 新建项目，或从 Overleaf 下载 ZIP 后导入。
2. 确认 `main.tex`、图片、`.bib` 和自定义样式均可编译。
3. 先建立无 AI 参与的基准 PDF。
4. 每次只让 AI 处理一个明确任务，例如修复一个报错或审查一个段落。
5. 阅读 diff 或修改位置，不直接接受大范围改写。
6. 重新编译。
7. 检查公式、交叉引用、引用和版面。
8. 对重要版本额外导出源文件与 PDF。

## 安全提示词

```text
请只修改我指定的 LaTeX 片段。
不要增加材料中不存在的实验结果、引用或贡献。
请先解释修改原因，再给出最小修改方案。
所有引用候选必须标记为“待人工核验”。
不要改变公式含义、符号定义和结论强度。
```

## 编译错误处理顺序

1. 从日志中的第一个错误开始，而不是最后一个。
2. 确认缺失文件、路径和包。
3. 检查括号、环境和自定义命令是否闭合。
4. 缩小问题范围：注释章节，再逐段恢复。
5. 让 AI 解释错误和提出最小修复。
6. 应用后重新编译，不能仅凭 AI 说明宣布修复。

## 从 Overleaf 迁移到 Prism

迁移前先检查：

- 项目是否依赖特殊编译器或自定义脚本；
- 图片路径是否相对当前 `.tex` 文件；
- `.bib`、`.sty`、字体和生成文件是否完整；
- 合作者是否都能访问新平台；
- 单位和合作项目是否允许上传材料。

推荐流程：

```text
Overleaf 导出 ZIP
→ 本地解压并留档
→ 导入 Prism
→ 无修改编译
→ 对比 PDF
→ 再启用 AI 修改
```

不要一边迁移一边重写论文，否则出错时无法区分是平台差异还是内容修改。

## 何时不应使用 AI 自动改写

- Method 中的关键定义；
- 实验设置和数据口径；
- 数学证明；
- rebuttal 中对审稿人的事实回应；
- 涉及保密结果的段落；
- 你自己还无法解释的内容。

AI 可以帮助发现问题，但论文作者必须能独立解释每个主张、公式、表格和引用。

## 最终检查

- [ ] PDF 可从干净项目重新编译
- [ ] 没有未解析引用或交叉引用
- [ ] 所有数字能追溯到实验文件
- [ ] 所有引用人工核验
- [ ] AI 没有扩大结论
- [ ] 重要版本已导出并留档
- [ ] 合作者知道当前唯一有效版本
