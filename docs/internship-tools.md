# 研究生实习求职工具链

求职工具链的目标不是把简历做得花，而是把项目证据、投递记录、面试复盘和能力缺口管起来。

## 最小工具组合

| 任务 | 推荐工具 |
| --- | --- |
| 简历版本 | Markdown / Word / Overleaf |
| 项目证据 | GitHub、截图、实验报告、README |
| 投递管理 | Notion、Excel、飞书表格 |
| 面试复盘 | Markdown、Obsidian、Notion |
| 八股和项目追问 | Anki、Markdown 卡片、AI 模拟面试 |
| 代码练习 | LeetCode、GitHub、代码笔记 |

## 投递表字段

```text
公司
岗位
地点
投递渠道
JD 链接
简历版本
项目匹配点
投递日期
当前状态
一面/二面/HR 面时间
面试问题
复盘结论
下一步动作
```

## 项目证据包

每个写进简历的项目都应该有一个证据包：

```text
project-evidence/
├── README.md
├── architecture.png
├── demo-screenshots/
├── experiment-report.md
├── bad-cases.md
├── metrics.md
└── interview-qa.md
```

## 简历项目检查

每个 bullet 写完后问自己：

- 这句话对应我亲手做过什么？
- 有代码、文档、日志、截图或实验记录支撑吗？
- 指标口径能解释清楚吗？
- 如果面试官追问 3 层，我能答到哪里？
- 有没有把团队贡献写成个人贡献？

## AI 怎么辅助求职

可以根据 JD 提取能力要求、检查简历匹配点、根据项目材料生成追问树、模拟面试官连续追问、帮你复盘回答漏洞。

不要编造项目经历、上线规模和指标，也不要把没做过的内容写成负责。
