# AI 辅助科研提示词与核验模板

提示词不能保证正确，真正可靠的是：限定材料、要求证据、区分事实与推测、执行独立核验。

## 通用约束头

建议放在每个科研提示词前：

```text
只基于我提供的材料回答，不要引入材料外事实。
如果证据不足，明确写“材料不足”。
区分：已由材料支持、需要核验、你的推测。
所有论文、数字、实验结果和引用必须标注来源位置。
不要编造论文、引用、数据、指标、代码运行结果或实验设置。
不要因为我的观点而默认赞同，请优先寻找反例和隐含假设。
```

## 论文快筛

```text
请根据我提供的标题、摘要、引言贡献段和实验概览，输出：
1. 论文研究问题；
2. 作者声称的贡献；
3. 方法核心操作；
4. 数据集、baseline 和指标；
5. 最重要的结果；
6. 作者承认的限制；
7. 仍需人工阅读的位置；
8. 与我的研究问题的关系。
每项标注来源位置。不要把作者主张当成已验证事实。
```

## 文献矩阵

```text
请把这些论文按统一字段整理：问题、假设、方法、数据、baseline、指标、主要结果、限制、closest-work 关系。
每个单元格必须能定位到原文。
无法确认时留空并写“待核验”，不要根据常识补全。
最后列出论文之间不可直接比较的原因，例如模型规模、数据、预算或指标差异。
```

## Idea 严格审查

```text
请作为严格审稿人，不要鼓励我。
审查以下 idea：
- 问题是否真实且明确；
- 是否只是把 A 用到 B、增加模块或扩大规模；
- 与 closest work 的机制差异；
- 隐含假设和替代解释；
- 什么结果会否定核心假设；
- 最低成本验证方案；
- 即使补实验也无法修复的问题。
每项给出严重程度和验证路径。材料不足时直接指出。
```

## 实验设计审计

```text
请检查这份实验设计是否能区分不同解释。
逐项审查：假设与预测、baseline、公平性、控制变量、数据泄漏、随机种子、统计报告、消融、failure case 和计算成本。
输出格式：问题、严重程度、为什么重要、当前证据、最小补充实验、什么结果能消除该问题。
不要只给笼统建议。
```

## Baseline 复现诊断

```text
不要直接猜测原因。
根据论文设置、代码版本、数据版本、环境、运行命令和当前结果，列出互相不同的候选原因。
按“数据与评价 → 官方配置 → 环境 → 随机性 → 实现差异”的顺序给出最小验证。
每次验证只能改变一个关键因素。
最后说明当前状态应标记为已复现、部分复现还是未复现。
```

## 代码调试

```text
先不要修改代码。
根据错误栈、最小复现、依赖版本、预期行为和实际行为，列出候选原因。
每个原因给出支持证据、反对证据和最小验证命令。
确认原因后再给最小补丁，并提供正常输入、边界输入和回归测试。
没有运行日志时不要声称已经修复。
```

## 数据分析审查

```text
请先确认变量含义、样本量、缺失值、分组方式、独立性和研究问题。
不要直接选择统计检验。
列出可能的分析方案及其假设、适用条件和失败条件。
特别检查多重比较、重复测量、数据不平衡、effect size、置信区间和相关性/因果性混淆。
```

## 论文段落审查

```text
请只检查表达和证据结构，不要增加材料外事实。
逐句标记：
- 纯语言问题；
- 逻辑跳跃；
- 缺少实验或引用支持；
- 结论强于证据；
- 术语或数字不一致。
给出更准确的改写，但保留原结论范围和限定条件。
```

## 引用核验

```text
根据我提供的论文原文和当前句子，判断该引用是否真正支持表述。
输出：支持全部、支持部分、不支持、材料不足。
指出具体章节或原文位置，并说明句子中哪些部分超出了论文证据。
不要生成新的引用。
```

## 模拟审稿

```text
分别以 novelty、实验严谨性、统计评估、系统成本和可复现性审稿人的身份独立评审。
每个角色输出：
1. 最可能拒稿的三个原因；
2. 缺失的关键证据；
3. 最危险的 closest work 类型；
4. 最低成本补强实验；
5. 仅靠写作无法修复的问题。
不要汇总成模糊的优缺点列表。
```

## 组会整理

```text
将这些实验日志整理为：研究问题、当前假设、关键证据、失败样本、未排除解释、当前判断、下一步实验、需要导师决策的问题。
不要把工作量当成结论，不要隐藏负结果，也不要编造缺失数字。
```

## 输出核验表

每次采用 AI 输出前填写：

```text
事实是否有来源：
引用是否打开原文核验：
数字是否与结果文件一致：
推断是否被误写成事实：
结论是否被语言放大：
代码是否实际运行：
测试是否覆盖边界情况：
是否包含敏感或保密信息：
最终采用和拒绝了哪些建议：
```

## 一个反面提示词

不要这样写：

```text
这是我的 idea，请告诉我它是不是很有创新，并帮我补齐论文和实验。
```

它会诱导模型迎合、补全缺失事实并跳过证据。应拆成问题审查、prior work 核验、假设审查和实验审计四个独立任务。
