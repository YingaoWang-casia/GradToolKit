# 工具数据库

`tools.yaml` 是 GradToolKit 的结构化工具库。它用于统一记录工具分类、适用场景、学习成本、替代品和避坑提醒。

## 当前分类

- `literature-management`：文献管理
- `paper-discovery`：论文发现
- `note-taking`：笔记
- `knowledge-management`：知识管理
- `writing`：论文和报告写作
- `experiment-management`：实验管理
- `experiment-tracking`：实验追踪
- `ai-research-assistant`：AI 科研助手
- `presentation`：汇报
- `diagramming`：画图

## 推荐评价字段

| 字段 | 含义 |
| --- | --- |
| `best_for` | 这个工具最适合解决什么问题 |
| `not_good_for` | 不适合拿它解决什么问题 |
| `works_well_with` | 推荐搭配 |
| `alternatives` | 替代工具 |
| `cautions` | 使用时容易踩的坑 |
| `learning_curve` | 学习成本，`low`、`medium`、`high` |
| `pricing` | 免费、付费或 freemium |

## 贡献优先级

优先补充真实用过、有明确研究生场景、能和已有工作流形成组合、有避坑经验的工具。

暂缓补充只有营销页面、付费门槛高、功能高度重复或数据边界不清的工具。
