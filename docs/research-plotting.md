# 科研绘图：从原始数据到可复现图表

科研图的目标不是“看起来高级”，而是让读者准确判断证据。

## 先回答图要证明什么

每张图制作前写一句：

```text
这张图要让读者看出：________。
```

如果一句话说不清，通常意味着：

- 一张图塞了太多问题；
- 图表类型不匹配；
- 你还没有明确想表达的研究结论。

## 工具选择

| 场景 | 推荐起点 | 主要风险 |
| --- | --- | --- |
| 批量实验、多个随机种子、自动化论文图 | Python / R | 需要维护脚本和环境 |
| 少量数据、快速探索 | Excel / Origin | 手工操作难以复现 |
| 常规统计和交互式分析 | GraphPad Prism | 自动化和版本管理有限 |
| LaTeX 内原生绘图 | PGFPlots / TikZ | 编译和维护成本较高 |
| 模型结构图 | PowerPoint / draw.io / Figma | 容易与真实实现脱节 |
| 矢量图后处理 | Inkscape / Illustrator | 手工修改后难以回溯 |

计算机与 AI 实验默认优先 Python 或 R，因为实验数量、随机种子和指标通常需要批量处理。

## 图表类型选择

- 比较少量类别：点图、箱线图、柱状图；优先显示原始点。
- 展示时间或训练过程：折线图。
- 展示分布：直方图、密度图、ECDF、箱线图或小提琴图。
- 展示两个连续变量关系：散点图。
- 展示矩阵或多组条件：热力图。
- 展示模型流程：结构图，不要伪装成数据图。

不要因为某种图“论文里常见”就机械使用。

## 误差线必须说明含义

图注中明确写：

- 样本量或随机种子数量；
- 中心值是均值还是中位数；
- 误差线是标准差、标准误还是置信区间；
- 是否进行了显著性检验；
- 多重比较是否校正。

只画均值和误差线但隐藏单次结果，会掩盖不稳定性。

## 坐标轴与视觉误导

检查：

- 柱状图纵轴是否从零开始；
- 截断坐标轴是否被明确标记；
- 对数坐标是否说明；
- 不同子图尺度是否一致；
- 面积、颜色和长度是否被错误地混合编码；
- 3D 效果是否扭曲读数；
- 配色是否适合色觉缺陷和黑白打印。

## 推荐目录

```text
analysis/
├── data/
│   ├── raw/
│   └── processed/
├── scripts/
│   ├── aggregate.py
│   └── plot_main.py
├── figures/
│   ├── fig1_main.pdf
│   └── fig1_main.png
├── tables/
└── README.md
```

论文图不应只存在于 PowerPoint、截图或某台电脑的软件历史记录中。

## 可复现绘图流程

```text
原始实验结果
→ 明确清洗规则
→ 聚合脚本
→ 绘图脚本
→ PDF/SVG 矢量图
→ 论文引用
```

最低要求：

- 脚本能从保存的数据重新生成图；
- 数据处理规则写在代码或文档中；
- 图中数字与论文表格使用同一数据源；
- 手工改图后保留可追踪记录。

## 导出格式

| 格式 | 适合 |
| --- | --- |
| PDF | LaTeX 论文中的矢量图、文字和线条 |
| SVG | 网页、矢量编辑和后处理 |
| PNG | 截图、界面图、像素图和预览 |
| JPG | 通常不适合文字和线条密集的科研图 |
| EPS | 仅在投稿系统明确要求时使用 |

位图需要足够分辨率；矢量图要检查字体是否嵌入、透明效果是否兼容。

## 模型结构图

结构图必须与代码一致。至少标注：

- 输入和输出；
- 训练阶段与推理阶段差异；
- 哪些模块有参数；
- 数据流向；
- loss 或监督信号位置；
- 关键张量形状，必要时标注。

不要为了视觉效果添加代码里不存在的模块。

## 图表审计清单

- [ ] 图回答了一个明确问题
- [ ] 图表类型与数据类型匹配
- [ ] 样本量和误差定义清楚
- [ ] 坐标轴没有误导
- [ ] 颜色不是唯一信息载体
- [ ] 图注可以独立解释图
- [ ] 数据和脚本可追溯
- [ ] 输出适合双栏和缩放阅读
- [ ] 图中结果与正文描述一致
- [ ] 失败结果没有被选择性隐藏
