# 第一次做文献综述

文献综述不是把论文摘要串起来，而是回答：这个方向的问题是什么，方法路线怎么演化，哪些贡献已经饱和，哪些 gap 还值得做。

## 适合谁

- 研一刚进组，需要两周内了解一个方向
- 准备开题，需要梳理相关工作
- 换课题，需要快速判断方向边界
- 写论文 related work，不知道怎么组织脉络

## 最小工具组合

| 任务 | 推荐工具 |
| --- | --- |
| 找种子论文 | Google Scholar, Semantic Scholar |
| 扩展论文网络 | ResearchRabbit, Connected Papers |
| 管理 PDF 和引用 | Zotero |
| 做文献矩阵 | Markdown 表格、Excel、Notion database |
| 写综述大纲 | Obsidian、Notion、Word、Overleaf |
| AI 辅助 | ChatGPT、Claude、NotebookLM、Elicit |

## 2 小时启动流程

1. 用 2 到 3 个关键词在 Google Scholar 搜索。
2. 找 1 篇综述、2 篇高引论文、2 篇近两年的论文作为种子。
3. 把种子论文导入 Zotero，并建立 collection。
4. 用 ResearchRabbit 或 Connected Papers 扩展相关论文。
5. 先筛 30 篇，不要一上来收 200 篇。
6. 复制 [文献综述矩阵](../templates/literature-review-matrix.md)。
7. 每篇只填：问题、方法、数据集、指标、创新点、局限、与你课题的关系。
8. 按“任务、方法路线、数据集、时间线”四种角度重新分组。

## 文献筛选标准

| 类型 | 至少保留几篇 | 用途 |
| --- | --- | --- |
| 综述论文 | 1-3 | 快速建立任务地图 |
| 奠基论文 | 3-5 | 理解问题定义和核心假设 |
| 近两年论文 | 8-15 | 判断当前趋势 |
| 最相似工作 | 5-10 | 判断自己的 novelty 边界 |
| 负面或失败线索 | 2-5 | 帮助写局限和实验设计 |

## 不要这样写综述

```text
A 提出了方法 A，取得了不错效果。
B 提出了方法 B，进一步提升性能。
C 使用深度学习方法，在数据集上表现较好。
```

这种写法没有脉络，也不能支撑你的研究问题。

## 更好的组织方式

```text
早期方法主要把问题建模为 X，因此依赖 A 假设；
随后工作转向 Y，以解决 B 场景下的限制；
近两年方法开始关注 Z，但多数仍没有处理 C 条件下的失败样本。
因此，本项目关注……
```

## 产出检查

一轮文献综述完成后，你应该能回答：

- 这个方向最核心的问题是什么？
- 代表性方法分为哪几条路线？
- 常用数据集和指标是什么？
- 最接近你的论文是哪几篇？
- 你的想法和这些论文到底差在哪里？
- 哪些实验结果会支持或否定你的想法？
