# 科研最小闭环

科研不是“读论文—想方法—跑实验—写论文”的单向流水线。它的核心是：提出一个可检查的问题，用能够区分不同解释的证据减少不确定性。

## 最小闭环

```text
观察现象
→ 定义问题
→ 检查已有解释
→ 提出可证伪假设
→ 推导可观察预测
→ 设计区分性实验
→ 分析结果与反例
→ 更新、修正或放弃假设
```

## 1. 观察现象

不要从“我想加一个模块”开始。先描述可重复观察的现象：

- 在什么条件下发生？
- 对哪些数据、模型或人群发生？
- 是否稳定超过随机波动？
- 是否可能由实现错误、数据泄漏或指标造成？

错误示例：

> 我想给 RAG 加一个图模块。

更好的起点：

> 当检索结果包含相关但相互冲突的证据时，模型倾向选择出现频率更高的答案，即使该答案来自较低质量来源。

## 2. 定义问题

研究主题不是研究问题。

```text
研究领域：大语言模型幻觉
研究主题：RAG 的事实一致性
研究问题：冲突证据下，哪些因素决定模型采纳哪条证据？
可验证问题：控制相关性和长度后，证据频率是否仍显著影响回答？
```

## 3. 检查已有解释

阅读 closest prior work 时，不只记录作者的方法，还要审计：

- 作者声称解决了什么问题？
- 实验真正证明了什么？
- 结论依赖哪些假设？
- baseline 是否公平？
- 是否存在未解释的反例？

## 4. 提出可证伪假设

一个有效假设必须允许出现反对它的结果。

```text
假设：冲突证据下，模型偏向高频答案主要由预训练先验造成。
预测：控制检索排序和文本长度后，偏置仍随答案预训练频率增加。
反证：频率效应消失，模型行为主要由检索位置或措辞决定。
```

无法说明“什么结果会否定我”的 idea，通常只是一个愿望或叙事。

## 5. 设计区分性实验

实验不是看指标涨没涨，而是区分解释。

至少写清：

- 自变量：主动改变什么；
- 因变量：观察什么；
- 控制变量：保持什么不变；
- 对照组：不用新机制时怎样；
- 备选解释：还有什么也能导致结果；
- 决策规则：不同结果分别意味着什么。

## 6. 分析结果

不要只报告平均分。检查：

- 多随机种子的方差；
- 不同数据子集；
- 失败样本类型；
- 性能、成本和稳定性的权衡；
- 结果是否只在有利设置成立；
- 结论是否超过实验能够支持的范围。

## 7. 更新判断

一次实验后只能做三种判断：

- **支持**：结果符合预测，且主要替代解释已被控制；
- **削弱**：部分结果成立，但边界或机制需要修改；
- **否定或无法区分**：证据反对假设，或实验设计不足以判断。

“效果不好，再调参数”不是结论。

## 每轮研究记录模板

```text
现象：
研究问题：
已有解释：
我的假设：
可观察预测：
最小区分实验：
可能的混杂因素：
结果：
当前判断：支持 / 削弱 / 否定 / 无法区分
下一步：扩展 / 修正 / 复查实现 / 停止
```

## 完成检查

- [ ] 问题不是方法名称的改写。
- [ ] 找到了最接近的已有工作。
- [ ] 假设可以被实验否定。
- [ ] 实验能够区分至少两个解释。
- [ ] 报告了方差、失败样本和适用边界。
- [ ] 失败结果会改变下一步，而不是被隐藏。
