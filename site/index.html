Workflow first

不是工具大全，而是可执行流程

文献综述

Scholar 找种子论文，ResearchRabbit 扩展网络，Zotero 管理 PDF，文献矩阵沉淀脉络。

论文阅读

先快筛，再结构化阅读，只有 closest prior work、baseline 和关键论文才深读。

实验管理

先用 Git 和 Markdown 日志管理，再按复杂度升级到 W&B、MLflow 或 DVC。

AI 辅助科研

AI 负责整理、改写和检查，论文结论、引用和实验数字必须回到原文和记录核验。

Reusable templates

Expected effect

预期效果

第一版上线后，它应该是一个能被研究生收藏、转发、照着做的工具箱，而不是一个看完就忘的工具清单。

  • 30 秒内知道项目有什么用
  • 按阶段找到自己的入口
  • 每个场景都有推荐工具、最小流程和避坑
  • 模板能直接复制使用
  • 别人可以通过 `tools.yaml` 贡献新工具
